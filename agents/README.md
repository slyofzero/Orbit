# agents/: full context for anyone (human or AI) working on Orbit

Start with `../AGENTS.md`, then read the file that matches your task.

1. `01-overview-and-principles.md`: what Orbit is, who it is for, the principles behind decisions
2. `02-architecture-and-files.md`: tech stack, folder map, what each important file does
3. `03-data-model-and-storage.md`: every saved key, profiles, backups, images, reset behaviour
4. `04-features-by-page.md`: each page and what it does, in user terms
5. `05-question-packs.md`: the question pack format, rules, limits, merging, editing
6. `06-plan-and-links.md`: plans, milestones, description, question links, import/export
7. `07-ai-prompts.md`: every prompt the app builds for AI chats, and the rules they share
8. `08-statistics.md`: events, mastery, view tracking, Excel export
9. `09-practice-exam-and-code.md`: answering, marking, mock exam rules, running code
10. `10-ui-and-styling.md`: CSS structure, themes, components, LaTeX rendering, accessibility habits
11. `11-testing-and-workflow.md`: tests, browser checks, shipping to the owner's machine
12. `12-owner-and-history.md`: owner preferences and the log of decisions

Keep these files current: when you change behaviour, update the matching file in the same change.
